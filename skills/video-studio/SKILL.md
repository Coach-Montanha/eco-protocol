# /video-studio — Incorporado ao Hub Mestre /insta

> **Status:** Este comando foi oficialmente unificado ao hub mestre **`/insta`** (ou `@insta`).

Ao executar `/video-studio`, o fluxo aciona diretamente o pipeline unificado do **`/insta`**:
- Edição local 100% com FFmpeg em formato 9:16 (1080x1920).
- Download e extração sem marcas via `cobalt`.
- Transcrição e análise local via `video-understand`.
- Narração neural brasileira com legendas palavra por palavra via `pixelle-video`.
- Modificadores de estúdio e Dual Real Video Engine.
