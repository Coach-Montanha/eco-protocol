# OpenReply — Instagram Automation Skill

Use this skill when developing, configuring, or integrating OpenReply Instagram automations, comment-to-DM flows, or chat triggers.

## Capabilities & Workflows

1. **Comment-to-DM Triggers**: Automatically respond to specific post/reels keywords by sending structured direct messages with CTA buttons.
2. **Interactive Flow Builder**: Design multi-step lead qualification trees (name, email, goal, booking link).
3. **API Integration**: Connect webhook events (`comment_received`, `dm_replied`) to external CRMs or webhooks.
4. **Token Economy**: Reuses pre-built JSON payload templates and native fetch handlers to avoid heavy dependencies.
