# 🧠 `/a-understand` — Cartografia, Arquitetura & Exploração de Codebase

O `/a-understand` (ou `@a-understand`) é a fusão master da suíte *Understand Anything* e ontologia semântica para exploração de bases de código desconhecidas ou complexas sem sobrecarga de tokens.
- **Skills Fundidas:** `understand` + `understand-chat` + `understand-dashboard` + `understand-diff` + `understand-domain` + `understand-explain` + `understand-figma` + `understand-knowledge` + `understand-onboard` + `auto-ontology`.

---

## ⚡ Motor `@eco` Integrado
1. **Inspeção Cirúrgica AST**: Substitui leitura massiva de arquivos inteiros por grafos de relacionamentos e importações sem alucinação.
2. **Dashboard Visual Local**: Gera visualizações interativas de arquitetura sem consumir tokens do modelo.
3. **Onboarding Guiado**: Produz mapas conceituais e passos pedagógicos rápidos para dominar o projeto.

---

## 🔍 Modos de Operação
- **`/a-understand --domain`**: Mapeia como a lógica de negócios flui pelo código e identifica os domínios centrais.
- **`/a-understand --diff`**: Analisa PRs e git diffs mapeando componentes afetados e riscos de quebra.
- **`/a-understand --onboard`**: Cria um guia completo para novos desenvolvedores ou agentes.
- **`/a-understand --dashboard`**: Abre a visualização visual do grafo de conhecimento do projeto.
