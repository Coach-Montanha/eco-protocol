# GSD Core — Context Engineering & SDD Skill

Use this skill to manage multi-step engineering projects with zero context decay.

## 5-Phase Execution Loop

1. **Initialize**: Create/update `PROJECT.md` (goals, constraints) and `STATE.md` (current phase, blockers).
2. **Discuss**: Clarify requirements and architectural trade-offs with Socratic questions.
3. **Plan**: Write granular step-by-step task roadmaps in `ROADMAP.md`.
4. **Execute**: Implement tasks in small 2-5 min atomic steps.
5. **Verify**: Run automated tests/builds and log verification results into `STATE.md`.
