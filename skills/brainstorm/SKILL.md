# Brainstorm — Interactive Design & Ideation Skill

Use this skill early in a feature or project lifecycle to explore approaches and align on technical design.

## Workflow

1. **Socratic Alignment**: Ask targeted, non-obvious design questions to clarify underspecified requirements.
2. **Alternative Exploration**: Present 2–3 viable architecture or UX trade-offs (e.g. Server vs Client state, REST vs WebSocket).
3. **Consensus & Specification**: Summarize agreed-upon design into a clean spec document before calling `/writing-plans`.
