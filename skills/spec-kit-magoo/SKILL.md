# Spec-Kit Magoo — SDD Pipeline Skill

Use this skill to orchestrate end-to-end Spec-Driven Development for complex features.

## Pipeline Stages

1. **`/brainstorm`**: Explore concepts, resolve ambiguity, define system boundaries.
2. **`/spec`**: Draft functional and non-functional specification document.
3. **`/writing-plans`**: Convert spec into step-by-step 2-5 min implementation tasks.
4. **`/execute`**: Execute tasks with continuous build/test verification and `@eco` token efficiency.
