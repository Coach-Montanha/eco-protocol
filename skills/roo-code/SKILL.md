# Roo Code — Multi-Mode Autonomous Agent Skill

Use this skill to execute tasks under specialized persona modes.

## Modes & Responsibilities

1. **Architect Mode**: System design, file structure planning, dependency analysis (`PROJECT.md` & diagrams).
2. **Code Mode**: Surgical feature implementation, refactoring, and component creation.
3. **Debug Mode**: Root cause diagnosis from full error tracebacks before code mutation.
4. **Ask Mode**: Read-only exploration and code explanation without making filesystem changes.
