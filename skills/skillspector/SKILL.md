# SkillSpector — AI Agent Skill Security Audit

Use SkillSpector to evaluate the safety, integrity, and permissions of agent skills and MCP tools.

## Key Capabilities
1. **Static Analysis**: Scans against NVIDIA SkillSpector rules (YARA patterns, AST checks, prompt injections, zero-width characters).
2. **Local Privacy**: 100% local execution with zero remote logging.
3. **Automated Audit**: Execute audit via `node C:\Users\Administrator\.gemini\config\sidecars\skillspector-scanner.js`.
